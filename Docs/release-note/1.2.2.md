## v1.2.2

### 让待办也成为桌面的一部分 | Highlight

v1.2.2 为花笺带来简约的玻璃待办磁贴：便签与待办共享统一外观，可在同一磁贴内切换；待办有独立保存，不会改写原有 Markdown 笔记。

#### 原生玻璃与主题

Windows 磁贴采用实时桌面合成模糊与圆角裁切，透明材质只影响背景，文字和勾选控件保持清晰。支持紫白、绿白、紫暗、绿暗四种配色，可跟随系统或在设置中手动切换。系统不支持原生效果时会回退为透明材质。

每张磁贴分别记忆不透明度，可在 5%–95% 之间以 5% 为步长调整；一张磁贴的设置不会影响其他磁贴。

#### 更顺手的待办操作

单击复选框即可完成或取消任务。按 Enter 连续新增一行，Shift+Enter 在当前任务中换行；支持键盘排序、删除和行内编辑。勾选框、对勾与关闭叉号会适配当前配色。

待办内容存放在独立数据文件中，与 Markdown 笔记分开保存。新增 `Ctrl+Alt+T` 呼出待办快捷键，并可在设置中录制或清除。

应用内版本检查现默认指向 RegulusApple 项目的 GitHub Releases。

### Bring To-dos onto Your Desktop | Highlight

Version 1.2.2 adds a minimalist glass to-do tile. Notes and to-dos share one visual style and can be switched from the same tile, while to-do data stays separate from existing Markdown notes.

#### Native glass and themes

On Windows, tiles use a live composited backdrop blur with rounded clipping. Transparency affects the material only, keeping text and controls crisp. Choose Purple Light, Green Light, Purple Dark, or Green Dark, and follow the system appearance or switch it manually in Settings. Unsupported systems fall back to a transparent material.

Each tile stores its own opacity, adjustable from 5% to 95% in 5% increments, without affecting other tiles.

#### Smoother to-do editing

Click a checkbox to complete or reopen a task. Press Enter to add the next item, or Shift+Enter to insert a line break within the current item. Tasks also support keyboard reordering, deletion, and inline editing. Checkboxes, check marks, and the close icon adapt to the selected theme.

To-do items are stored independently from Markdown notes. A new `Ctrl+Alt+T` shortcut opens to-dos and can be recorded or cleared in Settings.

In-app update checks now default to the RegulusApple GitHub Releases.

## 详细变更 | Changes

### 新增 | New

- 新增便签/待办模式切换和独立待办存储。
- 新增 Windows 原生玻璃背景、圆角磁贴及四种紫/绿明暗配色。
- 新增跟随系统/手动外观切换和逐磁贴独立不透明度（5%–95%，步进 5%）。
- 新增点击勾选、Enter 连续新增、Shift+Enter 换行、行内编辑与任务排序。
- 新增 `Ctrl+Alt+T` 待办快捷键及设置内快捷键录制。

### 改进与修复 | Improved & Fixed

- 让透明材质与文本/控件前景分层，避免内容随背景透明度一同变淡。
- 适配勾选框、对勾和关闭叉号的主题颜色与圆角显示。
- 加强待办保存、窗口间同步和快捷键冲突处理。
- 拆分 Markdown 格式化、快捷键录制与磁贴外观设置模块，便于维护。
